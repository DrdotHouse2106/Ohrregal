**Kurzbeschreibung (80 Zeichen):**
Musik, Hörbücher, Podcasts und Radio von deinem eigenen Server auf dem Fernseher.

**Beschreibung:**
Ohrregal bringt deine eigene Sammlung auf den Fernseher: Musik von deinem Navidrome- oder Subsonic-Server, Hörbücher und Podcasts von deinem Audiobookshelf-Server und deine Radiosender.

• Start mit „Spiel etwas für mich“, Weiterhören, neuen Folgen und zuletzt gespielten Alben
• Playlists, Künstler und Alben
• Hörbücher und Podcasts mit Kapiteln, Schlaf-Timer und Abgleich der Hörstelle
• Läuft auch beim Bildschirmschoner weiter
• Vom iPhone auf den Fernseher: Ohrregal auf dem iPhone übergibt, was gerade läuft

Ohrregal braucht einen eigenen Navidrome-Server und optional Audiobookshelf. Keine Werbung, kein Tracking, kein Konto beim Anbieter.

**Hinweis für die Prüfung (Englisch):**
Ohrregal is a client for self-hosted media servers. Test login: Navidrome server https://demo.navidrome.org, user demo, password demo. Optional Audiobookshelf: https://audiobooks.dev, user demo, password demo.
